STEP 8 — Use the Slack MCP to find the guardrail solution instructions
--------------------------------------------------------------------------------
Slack MCP: search.messages  query="guardrails solution instructions Unity Gateway"
Top actionable result (from a peer AI-challenge team, #fins-ai-challenge-team-cool):

  "Create a Unity Catalog SQL function <catalog>.<schema>.guard_block_all_data(prompt STRING)
   for use as an AI Gateway custom guardrail. Return TRUE (block) when the prompt
   attempts to read all/unfiltered customer data - patterns like 'all customers',
   'every account', 'entire dataset', 'read everything', 'unfiltered', 'no filter',
   'select *', 'list all customers'. Use a case-insensitive RLIKE. Then run two test
   SELECTs (one blocks, one passes)."

Supporting guidance (#ai-gateway):
  "AI Guardrails (service policies) only run on Unity AI Gateway model/MCP/model-provider
   services, not legacy /serving-endpoints. Create a model service and point the app to
   /ai-gateway/v1; configure OOB (PII) + custom (SQL / LLM-as-judge) guardrails; budgets =
   hard spend caps by user/team/use-case in the account console."

=> Implemented as perma_vm_catalog.northpeak_gateway.guard_block_all_data (see
   gateway_service.txt); verified: 'read all data ... select *' -> TRUE (block),
   'why is Store 214 short?' -> FALSE (allow).
