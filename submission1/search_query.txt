Natural Language Query: "stores with dead stock not selling"

Approach: Hybrid Full-Text + Vector Search on northpeak.inventory_notes

Extensions installed:
  - pgvector (vector 0.8.0) — for semantic similarity search (HNSW index, cosine distance)
  - pg_trgm — for fuzzy text matching (GIN trigram index)
  Notes: lakebase_vector and lakebase_text require shared_preload_libraries
         (server-side config); used pgvector + tsvector as the hybrid stack instead.

Table: northpeak.inventory_notes (20 rows from silver_inventory.merch_note_text)
Indexes:
  - idx_inventory_notes_fts: GIN on search_ts (tsvector, generated from merch_note + product_name + region)
  - idx_inventory_notes_trgm: GIN trigram on merch_note
  - idx_inventory_notes_embedding: HNSW vector cosine on embedding (8-dim keyword embeddings)

Query Vector for "stores with dead stock not selling":
  Dimensions: [dead_stock, clearance, overstock, no_sell, season_end, warm_cold, on_plan, steady]
  Embedding:  [0.5774, 0.0, 0.0, 0.5774, 0.0, 0.0, 0.0, 0.5774]

SQL Query:
WITH query_vec AS (
    SELECT '[0.5774,0.0,0.0,0.5774,0.0,0.0,0.0,0.5774]'::vector AS qv
),
fts AS (
    SELECT id,
           ts_rank(search_ts, to_tsquery('english', 'dead | stock | selling | movement | stagnant')) AS fts_score
    FROM northpeak.inventory_notes
    WHERE search_ts @@ to_tsquery('english', 'dead | stock | selling | movement | stagnant')
),
vec AS (
    SELECT n.id,
           1 - (n.embedding <=> q.qv) AS vec_score
    FROM northpeak.inventory_notes n, query_vec q
    WHERE n.embedding IS NOT NULL
)
SELECT n.store_id, n.product_name, n.region, n.on_hand_units,
       n.merch_note,
       n.markdown_risk_score,
       ROUND(COALESCE(f.fts_score,0)::numeric, 4) AS fts_score,
       ROUND(COALESCE(v.vec_score,0)::numeric, 4) AS vec_score,
       ROUND((COALESCE(f.fts_score,0)*0.4 + COALESCE(v.vec_score,0)*0.6)::numeric, 4) AS hybrid_score
FROM northpeak.inventory_notes n
LEFT JOIN fts f ON f.id = n.id
LEFT JOIN vec v ON v.id = n.id
WHERE COALESCE(f.fts_score,0) > 0 OR COALESCE(v.vec_score,0) > 0.3
ORDER BY hybrid_score DESC
LIMIT 8;
